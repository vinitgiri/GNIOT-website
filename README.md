# GNIOT Website

A modern and responsive college website designed for **GNIOT (Greater Noida Institute of Technology)**. The project provides students and visitors with an easy-to-use interface to explore college information, academics, departments, facilities, events, and other important resources.

## 🚀 Features

* 🏫 College overview and information
* 📚 Academic and department details
* 👨‍🎓 Student-focused sections
* 🏢 Campus and facilities information
* 📅 Events and announcements
* 📱 Responsive design for desktop, tablet, and mobile
* 🎨 Clean and user-friendly interface
* ⚡ Fast and easy navigation

## 🛠️ Technologies Used

* HTML5





> The folder structure may vary depending on the current implementation of the project.

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vinitgiri/GNIOT-website.git
```

### 2. Open the project

```bash
cd GNIOT-website
```

### 3. Run the website

If it is a static HTML 

```text
index.html
```

in your browser.

For development, you can also use the **Live Server** extension in VS Code.
